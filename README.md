LatPred-SG: Smart Grid Latency Prediction

This repository contains the simulation code and dataset for the thesis  
**"Transformer‑Based Method for Reducing Latency in Smart Grid Communication"**  
by Koroma Samuel Ansumana (Dalian University of Technology).

Contents

- `simulate_latency.py` – Python script that simulates an M/M/1 queue and compares GRU vs LatPred-SG.
- `smart_grid_latency_dataset.csv` – Generated latency traces (5000 packets).

Requirements

- Python 3.7+
- numpy, pandas, scikit-learn
