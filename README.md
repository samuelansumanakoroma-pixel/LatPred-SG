LatPred-SG

Transformer-Based Method for Reducing Latency in Smart Grid Communication

Overview

LatPred-SG is a transformer-based framework developed to predict and reduce communication latency in smart grid networks. The framework focuses on improving latency prediction under dynamic and burst communication traffic conditions within HAN–NAN–WAN smart grid architectures.

This repository provides representative implementation materials, sample datasets, and methodological documentation associated with the proposed framework.

Repository Contents

- NS-3 smart grid communication simulation configuration
- Traffic preprocessing examples
- Sample latency dataset
- Evaluation methodology
- Reproducibility documentation

Dataset

The dataset contains representative communication traffic samples generated under simulated smart grid communication scenarios including periodic monitoring traffic and event-driven burst traffic.

Objective

The objective of this work is to improve communication reliability and reduce latency prediction error in smart grid communication systems using transformer-based deep learning techniques.
