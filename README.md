# LatPred-SG: Discrete-Event Simulator for Smart Grid Latency

This repository contains the discrete-event simulation code used in the thesis  
**"Transformer-Based Method for Reducing Latency in Smart Grid Communication"**  
by Koroma Samuel Ansumana (Dalian University of Technology).

## Requirements
- Python 3.7+
- NumPy

Install: `pip install numpy`

## Run the simulation
```bash
python discrete_event_sim_correct.py
